Android preview for phones and tablets running Android 8.0 or later. Includes both 32-bit and 64-bit ARM.

Version 0.6 adds app update checks under More → App updates. Automatic checks run at most once a day when opening the library and can be disabled. Downloads are explicit; the APK size, SHA-256, package, newer version, Android compatibility and installed signing certificate are verified before Android's installer opens. Android requires installation approval and may first ask to allow updates from FlXtR. Library data and preferences are retained.

Includes compact phone layouts, selectable original and Touch themes, and immersive video with auto-hiding controls. Media features include movies/series, KissAnime, music/MTV, TV channels, Archive, local media, history, downloads and controller navigation. Moonlight and Libretro games are embedded. The initial Libretro core supports Game Boy/Game Boy Color (.gb/.gbc), including touch/gamepad input and save states. A separate Moonlight or RetroArch app is unnecessary. Moonlight requires a Sunshine/GameStream PC and pairing. Provider availability varies.

Preview limitations: physical gamepads and extended background playback need more testing. On the Android 8 Galaxy S7 edge, movie, anime and offline video passed; a music-runtime fix is included but still needs a hardware retest. Moonlight discovery/UI and native library load, Libretro patterned video/audio/state/controller checks and music seek passed on an Android 8 emulator. Live Moonlight streaming still needs a host test. This build is experimental.
