# Android 1013

Touch controls are hidden by default. Use the small game-menu button, then
Touch controls: On/Off to toggle them. The choice is remembered across games.
Physical controller input is unchanged.

Movie and episode playback can now discover external captions through the
provider's separate subtitle catalogue when none were returned with the video.
Norwegian Nynorsk language tags are recognized. Availability depends on the
provider and title; actual subtitle playback still needs device testing.

Existing embedded NES, SNES, GB/GBC, GBA and PlayStation cores are retained.
Additional Sega/PC Engine cores and embedded Dolphin, ScummVM and PPSSPP are
not included in this release.

Android 8+, ARM 32-bit and 64-bit. The native libraries are unchanged from 1012.
