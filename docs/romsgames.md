# RomsGames phone import

Games → Start / Get Games → second page → RomsGames (Phone).
Choose a console, then a game. Scan the QR code while your phone is on the
same network. The phone remote contains a link to that game's RomsGames page.
Complete the website's browser check and download there, then return to the
remote and upload the ROM or ZIP. Keep the QR screen open during upload.
Press B on the TV to close the screen and automatically import your games. ZIPs use the existing ZIP
browser. No PC is needed.

The catalogue is read-only, six titles per screen, ordered by the site's
popularity list. JSON pages use the normal catalogue cache. The adapter
currently expects 36 titles per website page. A site redesign may require
an adapter update. It never requests the CAPTCHA-protected download API.
Only HTTPS RomsGames game paths can become phone links; links open without
the private phone-session URL as a referrer.

Uploads currently support NES, SNES, GB/GBC, GBA and ZIP ROM files, up to
512 MB. Extract RAR/7z files on your phone first. Supported console folders
are discovery categories, not a promise every game/core works or runs fast.
Large PlayStation/PSP discs may require the existing USB/import workflow.
