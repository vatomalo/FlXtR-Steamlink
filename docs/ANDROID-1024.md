# Android 0.10.24: Turkish subtitles

Adds Turkish under Settings > Playback > Subtitle language. Caption tracks
labelled Turkish, Türkçe, tr, tr-TR or tur are recognised as Turkish.
Selecting Turkish prefers available Turkish subtitle tracks; availability
depends on the video source.

Includes the embedded game engines from 0.10.23. Existing libraries and settings
are preserved when installing over the existing app. Older previews with the
128 MB updater limit need one direct APK installation. Android asks for
installation approval.

The subtitle language tests and release build checks pass. Native engines are
unchanged from the A52-tested 0.10.23 release.
