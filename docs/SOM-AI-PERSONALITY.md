# AI personality speech bubbles (experimental)

The Secret of Mana AI can now display non-modal, pixel-art speech bubbles
using the existing Libretro video overlay. No game memory, save or ROM is
modified by the speech renderer. The overlay receives a message beginning with
`^` for a speech bubble; ordinary messages still draw in the bottom status box.

Speech is contextual, short and throttled (one line per 12 seconds, same event
at most once per 24 seconds). Current events include exploration, fights,
retreating, being stuck, entering a new verified map and taking damage.
Nothing is generated by Ollama yet: the lines are deterministic personality
presets, with varied phrasing and no inference delay.

Presets: `curious` (default), `bold`, `dry`.

Run manually:

```sh
python3 tools/som_qwen_bridge.py --policy hybrid --wram-remote \
  --ring-control --steps 0 --personality dry
```

To disable quips without disabling the existing status messages:

```sh
python3 tools/som_qwen_bridge.py --policy hybrid --wram-remote \
  --ring-control --steps 0 --no-personality
```

For the supervised service, add `--personality dry` to the bridge invocation,
or use its normal default (curious). The service installer may require a
separate configuration change to make a particular preset persistent.

### Build and tests

```sh
git switch feature/som-ai-memory-agent-20261112
git pull --ff-only
PYTHONPATH=tools python3 -m unittest tools/test_som_personality.py -v
python3 -m py_compile tools/som_personality.py tools/som_qwen_bridge.py
bash scripts/build-som-ai-proxy.sh
```

The new speech rendering requires reinstalling the rebuilt
`som_ai_proxy_libretro.so` into the experimental core location and
restarting the game. Do not overwrite the vanilla Snes9x core.

**Current limitation:** the bubble is anchored near the central player region
in screen space. It does not yet follow the exact actor on screen because a
camera-coordinate transform has not been verified. It cannot be distinguished
from the vanilla game's native dialogue system by ROM logic; it is a harmless
video overlay. Native event text, multiline dialogue and fully model-written
character dialogue are separate future tasks.
